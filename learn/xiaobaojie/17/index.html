二、核心定价工具：戈登增长模型与四大因子

04:24 - 11:45

今天用的公式是戈登增长模型——专业说法是"恒定增长的股利贴现模型"，主要给"能稳定分红且分红增速稳定"的权益类资产做估值。

特别提醒：这是一个为理解宏观传导逻辑而简化的"魔改版"模型，只能用来理解逻辑，千万不能在现实中直接套用公式给资产做绝对数值定价。

核心公式

资产价格 = [ 当前现金流 × (1 + 增长率) ] ÷ [ (无风险利率 + 风险溢价) − 增长率 ]

四大因子

因子位置含义
当前现金流分子资产当年的实际收益：股息、债券利息、房租租金。股价价差、房价涨幅等价差不属于现金流。
增长率分子+分母现金流的预期年化增长率。最重要：同时影响分子和分母（分子乘它变大，分母减它变小）。
无风险利率分母通常指十年期国债收益率。
风险溢价分母对风险资产所要求的额外补偿（如股票、房产、信用债存在本金亏损风险，需给补偿）。

通俗理解：资产价格由这四个因子"共振"产生。记两个口诀——分子变大（现金流↑、增长率↑）= 涨基本面；分母变小（无风险利率↓、风险溢价↓）= 涨估值。

三、数字代入：一个公式看懂资产价格

11:45 - 14:53

用"房子"举例，把数字带进公式感受每个因子的作用。基准情景：

参数数值代入公式位置
房租（当前现金流）12 万/年分子 → 当前现金流
增长率3%分子+分母 → 增长率
无风险利率2%分母 → 无风险利率
风险溢价4%分母 → 风险溢价
房价（结果）412 万——

由此可得：一个资产的价格，是四大因子共同共振的结果。接下来逐个因子讲：每个因子怎么影响价格，货币政策又怎么影响这个因子——完整传导链路就此打通。

价格驱动拆解：分子端（现金流变大、增长率放大分子）= 基本面驱动；分母端（无风险利率/风险溢价变小、增长率缩小分母）= 估值驱动。增长率最特别——它同时贡献两端。

四、因子一：增长率——影响最剧烈，也最难改变

14:53 - 20:56

其他条件不变，只改增长率，看房价变化：

情景增长率房价对比 412 万
经济走强3% → 5%1260 万约 +200%（翻近3倍）
经济衰退3% → -1%170 万约 -60%

为什么增长率影响最明显

  • 公式里增长率既在分子又在分母：分子上"加上"增长率放大分子；分母上"减去"增长率缩小分母——上面变大、下面变小，除出来的数字被双重放大。
  • 结论：增长率和资产价格正相关（同向变化）。经济基本面哪怕只有一个小小的变化，对资产价格的影响都是巨大的。

但增长率最难改变

想提升增长率，必须改变经济本身——而降息等货币政策对经济只是间接推动。所以：基本面起来很难，但一旦起来，对整个资产价格的影响剧烈而长远。

一句话：增长率=分子分母双引擎，撬动价格最猛；但它是"慢变量"，要靠经济基本面的真实回升。

五、货币政策如何影响增长率

20:56 - 24:47

货币政策能否影响增长率？能，但走的是间接传导链。以房子为例：

宽松（降息/降准/QE）的传导链

  • 量化宽松 → 基础货币供给增加 → 借贷成本下降 → 促进投资和消费；
  • 投资消费转好 → 企业收入增加 → 给员工发工资 → 居民收入增加；
  • 收入增加 → 间接推升房租增长率 → 套进公式 → 资产价格上涨。

紧缩（加息/升准）的传导链

  • 量化紧缩 → 基础货币供给减少 → 信贷成本上升 → 抑制投资和消费；
  • 企业收入减少 → 居民收入减少 → 降低房租增长率 → 套进公式 → 资产价格下跌。

核心：宽松的货币政策容易导致资产上涨、紧缩导致资产下跌——背后是完整的传导链路，不是市场情绪那么简单。货币政策直接影响现金流的增长率，而增长率在分子分母上都有，直接作用到资产价格。

六、因子二：无风险利率——传导、极限与估值泡沫

24:47 - 36:32

其他条件不变，只改无风险利率（10年期国债收益率）：

情景无风险利率房价对比 412 万
央行降息2% → 1%618 万约 +50%
央行加息2% → 5%206 万约 -50%（腰斩）

结论：无风险利率和资产价格负相关——加息资产跌、降息资产涨。

降息如何传导到10年期国债收益率

  • 央行降政策利率（7天逆回购利率）→ 银行间利率跟着下降；
  • 银行拿到便宜钱 → 跑到国债市场套利（资金成本低、国债不违约，价差=无风险套利）；
  • 买国债的银行增多 → 国债价格抬升 → 倒算回来国债收益率下降；
  • 银行从短期限套到长期限（1年→3年→5年→10年），逐级传导，直到利差被"套平"——政策利率最终与10年期国债收益率基本拉平。

降息的极限：分母不能无限小

  • 政策利率理论上最低到 0 或接近 0，再往下没有空间（日本负利率是"储蓄端"为负，政策利率从未为负）；
  • 单靠降息缩小分母有限——降不动了，纯靠估值拉动就会形成估值泡沫；
  • 要等长牛，必须等基本面（增长率）回升；降息降不动时，只能靠另外两个因子——增长率和风险溢价——动起来。

推论：这就是全球资本市场如此关注央行降息/加息的原因——它直接决定资产价格的方向。但"单边降息"的力量有天花板，真正的行情需要分子（基本面）跟上。

七、因子三：风险溢价——主观与客观的八种风险

36:32 - 44:38

风险溢价是各种风险的集合，是四个因子中最复杂、最难量化的一个（涉及人性和市场情绪）。它不是算出来的——只有资产价格出来之后倒推，才知道里面包含了多少风险溢价，因此它是市场非理性波动的主要来源。

主观类（我主观认为有风险）

类型含义
不确定性明确知道有风险，但不知道何时何地以何种方式发生（"知道自己不知道"）。
风险偏好知道风险、知道承受能力，权衡后仍选择承受（"知道自己知道"）。
认知偏差如"黄金永远涨""房子永远不跌"——不知道自己不知道（缺乏常识）。
情绪偏差知道有风险仍管不住手、追涨杀跌——非理性行为，被情绪控制。

客观类（机制与市场结构）

类型含义
流动性变现的难易程度。钱多、好卖 → 流动性好 → 风险溢价低；钱少、卖不掉 → 风险溢价高。
制度机构考核/机制影响行为：公募年底考核减仓；开放式指数基金完全按申赎驱动买卖。
算法量化交易（趋势跟随）放大市场波动：涨时追涨、跌时杀跌。
期限风险的放大器：时间越长、不确定性越高、风险溢价越高。

关键：风险溢价=主观×客观多因素共振，无法预先量化 → 市场"没道理的涨跌"多源于此（如美债长期风险溢价上升 → 美债价格下跌、收益率上涨）。

八、货币政策如何影响风险溢价（三种方式）

44:38 - 1:08:14

先看数字：其他条件不变，只改风险偏好（风险溢价）。

情景风险溢价房价对比 412 万
大家更爱冒险4% → 3%618 万约 +50%
大家更保守4% → 8%177 万约 -57%

结论：风险溢价和资产价格负相关。风险偏好越高（更爱冒险）→ 需要补偿越小 → 溢价越低 → 资产越贵。

央行拿捏风险溢价的三种方式

方式机制特点
①注入流动性QE/降准/逆回购把钱灌进市场 → 接盘的人变多 → 变现难度降低 → 解决"市场缺钱的焦虑" → 风险溢价下降立竿见影：喊大放水，资产立刻爆拉
②降低不确定性央行喊话/预期管理/前瞻指引 → 把底牌亮出来 → 市场怕的是"不知道明天发生什么" → 信心像"手电筒"：路没变、坑没变，但恐惧减少 → 风险溢价下降给的是预期和信心（信心比金坚）
③压低无风险利率低利率/下场买国债 → 无风险收益太低 → 资金从安全区"挤"向风险区 → 风险资产价格被顶上去 → 风险溢价被动下降慢慢发酵：需逐级传导，动作不快

总结：宽松 vs 紧缩

  • 宽松（放水、降息、QE）→ 压低风险溢价 → 分母变小 → 资产价格容易上涨；
  • 紧缩（加息、抽水、QT）→ 风险溢价走扩 → 分母变大 → 资产价格下跌。

典型案例：沃什上台主张紧缩（QT）→ 资产价格暴跌——理解了定价链路，就能对政策效果提前预判。更关键的一条：经济基本面差（分子差）时，只要央行疯狂放水压低分母，依旧能让资产"由熊转牛"——只是这是"分母端的红利吃掉分子端的利空"驱动的水牛/估值牛。

九、案例一：PSL棚改核动力——三因子共振

1:08:14 - 1:22:00

PSL（抵押补充贷款），江湖外号"棚改核动力"——结构性货币政策工具。2015-2018年，它推动三四线城市房价暴涨。用定价公式复盘：PSL让三个因子共振（只有无风险利率没变——因为它是结构性工具，不是全面降息）。

因子PSL 的传导
当前现金流 ↑拆房子（真拆）→ 低价房源减少 → 但租房需求还在 → 净需求上升 → 租金底座上移 → 房租整体上涨 → 现金流变大
增长率 ↑拆迁户手握几百万 → 抢房大军入市 → 房价房租有了进一步上涨的预期 → 增长率预期抬高
风险溢价 ↓①不确定性降：国家队（超级买家）下场，大家有了"国家都来买"的底气；②风险偏好升：手里钱多"输得起"，求富心态；③情绪偏差升：踏空焦虑战胜理智，不管给不给补偿都要买

结果：分子（现金流、增长率）与分母（风险溢价）全面共振，房价像飞了一样。连一个结构性工具都能对资产产生如此深远的影响——这正是货币政策威力的缩影。

复盘逻辑：PSL=国家给钱 → 拆迁户带钱入市买库存房 → 低端房源减少租金涨 + 上涨预期 + 国家队兜底信心 → 现金流↑、增长率↑、风险溢价↓，三箭齐发。

十、案例二：924新政——四因子全面共振

1:22:00 - 1:44:08

2024年9月24日，央行推出一揽子货币政策，让股市由熊转牛。它超越传统降息降准——让定价模型中的所有四个因子同步改变并共振。

因子924 的传导
当前现金流 ↑股票回购增持再贷款（央行低息给商行 → 商行借给上市公司/股东 → 回购+注销股票）→ 总股本减少 → 净利润不变但 EPS 被动升高 → 每股现金流上升
增长率 ↑降准 0.5pct + 政策利率下调 → 引导 LPR/贷款利率下行 → 企业财务费用下降 → 净利润被动上升 → 分红能力变强、可投资资金变多 → 市场对增长率的认知从悲观修正到中性甚至乐观
无风险利率 ↓7天逆回购降 20BP（1.7%→1.5%）→ 带动10年期国债收益率中枢下移
风险溢价 ↓①流动性：互换便利——机构用股票/ETF 换央行国债/央票，随时可质押融资 → 不再被迫砸盘卖股票 → 流动性焦虑解除；②不确定性：政治局会议把"稳股市"写入定调文件 + 配套工具 → 尾部风险消失；③风险偏好：明牌（回购增持再贷款 2.25% 成本 < 股息率 → 套利机会，激发贪婪）+ 暗牌（国家队兜底预期，压制恐惧）→ 风险偏好迅速翻转

为什么威力如此之大

  • 回购注销直接抬升每股现金流（分子）；降息降准释放利润、抬高增长预期（分子+分母）；7天逆回购带动无风险利率下行（分母）；互换便利+政治局定调+明暗两张牌压缩风险溢价（分母）。
  • 四因子全部共振 → 分子分母同向利好 → 股价脉冲式上涨（戴维斯双击：既涨估值也涨基本面）。
  • 货币政策的威力不是三五天的情绪影响，而是改变定价因子的方向与强弱。

核心认知：股市反转不是"谁喊了个口号"，而是一系列政策推动，根源在上游的货币政策——它是资产涨跌最重要的上游因素。

十一、读政策方法论：先判级别，再评效率

1:44:08 - 2:04:07

面对庞杂的货币政策，读法分两步：先判断级别，再评估效力。

第一步：判断级别——看决心 + 看配套

维度判断要点
决心"尽力而为"（常规喊话，如"保持流动性合理充裕"=正确的废话，市场无反应）vs "不惜一切代价"（央行行长亲自站台、拿出超常规工具、给出具体数字，如潘行长"首期5000亿，不够再5000亿，再不够第三个5000亿"=上不封顶的承诺）→ 超常规操作才能消灭不确定性风险溢价。
配套央行"独角戏"（仅降息）vs "大合唱"（最高领导定调 + 央行降分母 + 财政拉分子）。央行单打独斗只能降分母（有限），解决不了分子（实体盈利能力）问题；多方协同才能把短暂反弹变成长期反转。

第二步：评估效率——看作用点 + 看传导链

  • 政策在动利率还是动流动性？动利率 → 压无风险利率 → 估值抬升；动流动性 → 压风险溢价。结构性工具只改善企业成本 → 偏分子端。
  • 资金流向生产端还是需求端？效果差的：流向生产端（间接）；效果好的：直达需求端（直接给到会马上买资产的人手里）——如 PSL 给拆迁户买房、924 给上市公司回购。
  • 传导链越短越好：链路长则摩擦大、力度打折；"精准投喂"式直达（最短链路）威力最大——形成真实买盘，还能间接改善分子端。

推绳子理论：为什么降息没效果

现在绝大多数政策几乎都是单边（只降息），分母变小但分子端经济预期差、增长率被往下修——分子的悲观吃掉分母的利好，所以降息效果不大。拉绳子一拉就直，推绳子怎么都推不动。分子（基本面）和分母（流动性）一起向好，才会出现真正的"戴维斯双击"。

未来方向：结构性货币政策成为主流（中央经济工作会议、十五规划后仍是结构性工具）——必须追踪钱的最终流向，流向资产端才有效。

十二、终极心法：分母定生死，分子定高低

2:04:07 - 2:14:05

为什么花这么大精力拆解货币政策？不是为了预判央行（那是神仙干的事），而是央行"出牌"时能第一时间看懂桌上的局势。

心法：分母定生死，分子定高低。

  • 分母定生死：流动性环境决定市场"有没有行情"。央行舍得放水、利率下降、风险溢价压缩，价格就可能起飞。
  • 分子定高低：经济基本面决定行情"走多高、走多远"。只有基本面跟上、增长率起来，才能涨得久、涨得多，成为长牛。
  • 大牛市 = 基本面和流动性共振（分子分母同向共振）——这就是"王炸时刻"。

投资动作

  • 识别它，抓住它——王炸时刻不会每天都来，人生抓住关键几次就足够（行情周期长）；
  • 躺平不下车——不要做短线、不要上蹿下跳，短期的波动根本不看；
  • 耐心等风停——何时结束？当公式里影响价格的关键指标发生逆转，行情就结束了。

定位：这套框架通用、结论不通用——每项政策用了几成效率取决于微观传导路径，需一事一议。但有了框架就不会像无头苍蝇。货币政策系列至此讲完，下次课进入第二趴：宏观经济（会与货币政策勾稽起来讲）。

课程知识卡片（专业版）

以下为课程配套的专业版知识卡片，标题为"货币政策第17期：课程总结——资产定价、货币政策与戈登增长模型"，汇总了本期核心知识点的完整框架。

专业版卡片文字摘要

  • 一、核心定价工具：戈登增长模型。知识点1：戈登增长模型及其四大因子。核心公式：资产价格=[当前现金流×(1+增长率)]÷[(无风险利率+风险溢价)-增长率]。四大因子：当前现金流（当年的实际收益，如股息/房租）、增长率（预期年化增长率，最重要——同时影响分子和分母）、无风险利率（十年期国债收益率）、风险溢价（对风险资产的额外补偿）。特别注意：这是简化魔改版，不可直接套用公式做资产绝对定价。
  • 二、货币政策如何通过四大因子影响资产价格。知识点2：货币政策对各因子的影响路径。价格上涨驱动力=分子端（现金流变大、增长率放大分子="基本面驱动"）+分母端（无风险利率/风险溢价变小、增长率缩小分母="估值驱动"）。宽松政策：①影响增长率（分子/分母）——降低借贷成本，推动投资消费、降低财务费用，抬升增长率预期；②影响无风险利率（分母）——降息经银行间套利压低十年期国债收益率；③影响风险溢价（分母）——注入流动性缓解"钱荒"、预期管理消除不确定性、压低无风险利率把资金从安全区"挤"向风险区。实践运用：一次成功的宽松同时作用于分子分母，形成"戴维斯双击"，引发资产价格剧烈上涨。
  • 三、历史复盘与心法总结。知识点3：如何判断货币政策的级别与效率。判断级别：看决心（"尽力而为"常规喊话 vs "不惜一切代价"央行行长站台+超常规工具）与配套（央行"独角戏" vs 最高领导定调+央行降分母+财政拉分子的"大合唱"）。评估效率：看作用点（资金流向生产端=间接 vs 需求端=直接给资产购买方）与传导链（链路越短效果越好；PSL、924新政是资金直达需求端的典范）。课程总结：真正的"王炸"级政策=最高层定调、多部门协同、资金直达需求端的组合拳，同时引爆基本面和估值，创造趋势性行情。

极简版卡片文字摘要

  • 第一部分：课程核心知识点。戈登增长模型=给资产估价的"计算器"（魔改版，只用于理解逻辑，不能直接给股票定价）。四大因素：①当前现金流（分子）：今年能收多少房租/股息；②增长率（分子/分母）：预计明年的房租/股息能涨多少——最厉害，同时让分子变大、分母变小；③无风险利率（分母）：十年期国债收益率；④风险溢价（分母）：冒风险投资所要求的"多给的那部分钱"。央行=同时操控四个按钮的"大玩家"：降息/降准时 1)直接降低无风险利率 2)让企业借钱成本变低、提高增长率预期 3)向市场放水、降低风险溢价——分子变大、分母变小，资产价格"坐上火箭"。
  • 第二部分：资产配置实战心法。为什么央行降息市场没反应？"推绳子"——经济差（分子端增长率悲观）时，即使央行努力降息缩小分母，分子的悲观也会把分母的利好抵消；只有分子（基本面）和分母（流动性）一起向好，才有真正的"戴维斯双击"。怎么判断货币政策"含金量"？看决心（常规喊话 vs 央行行长亲自站台+前所未有的新工具）+看配套（央行独角戏 vs 最高领导定调+央行降估值+财政部拉经济的"大合唱"）。什么样的政策最能推动资产价格上涨？看钱流向哪里——效果差：流向"生产端"；效果好：直接流向"需求端"（PSL棚改直接给拆迁户发钱买房、924新政给上市公司低息贷款回购股票）——"精准投喂"传导链路最短，形成真实买盘，威力最大。
  • 爆姐金句："分母定生死，分子定高低。"分母=市场的流动性环境，决定市场"有没有行情"（央行肯放水，市场就不会太差）；分子=经济的基本面，决定行情"走多高、走多远"。一轮真正的大牛市，一定是基本面和流动性共振的结果。学习宏观，就是要努力识别那个分子、分母同向共振的"王炸时刻"！
